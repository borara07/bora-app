# 보관해 둔 객관식 문제 (5지선다 4개)

01회를 OX 문제로 새로 만들면서 잠시 빼 둔 문제입니다.
나중에 객관식 회차를 만들 때 이 내용을 그대로 쓰면 됩니다.

```js
      /* ---------- 5지선다 4문제 ---------- */

      {
        ask: "다음 단어를 맞춤법에 맞게 수정한 것으로 적절하지 않은 것은?",
        choices: [
          "법썩 → 법석",
          "년도 → 연도",
          "합격율 → 합격뉼",
          "짭잘한 → 짭짤한",
          "뭉둥그려 → 뭉뚱그려"
        ],
        answer: 3,
        explanation: "'합격률'이 옳습니다. '렬, 률'을 '열, 율'로 적는 것은 모음이나 'ㄴ' 받침 뒤일 때인데, '합격'은 'ㄱ' 받침으로 끝나므로 '합격률'입니다."
      },
      {
        ask: "〈보기〉의 단어들을 표기가 올바른 것끼리 바르게 짝 지은 것은?",
        sentence: "선률, 확률, 남여노소, 고운 피부가 돼요, 옷 다립니다, 불을 붙이다, 민밋하고, 야단법썩",
        choices: [
          "선률, 확률, 고운 피부가 돼요, 불을 붙이다",
          "선률, 고운 피부가 돼요, 옷 다립니다, 야단법썩",
          "확률, 남여노소, 고운 피부가 돼요, 옷 다립니다, 불을 붙이다",
          "확률, 남여노소, 옷 다립니다, 불을 붙이다",
          "확률, 고운 피부가 돼요, 옷 다립니다, 불을 붙이다"
        ],
        answer: 5,
        explanation: "바른 표기는 '확률, 돼요, 다립니다, 붙이다' 넷입니다. 틀린 것은 선률(→선율), 남여노소(→남녀노소), 민밋하고(→밋밋하고), 야단법썩(→야단법석)입니다."
      },
      {
        ask: "띄어쓰기가 적절하지 않은 것은?",
        choices: [
          "잠을 잔듯 만듯 정신이 하나도 없다.",
          "사월로 접어든 지 며칠 안 돼 고모는 산기를 보이기 시작했다.",
          "이번 주 내내 하늘을 뒤덮었던 비구름이 물러났다.",
          "무엇을 그리든지 잘만 그려라.",
          "아버님 평생 동안 양식 걱정 안 하시도록 해 드릴 겁니다."
        ],
        answer: 1,
        explanation: "'잔 듯 만 듯'으로 띄어 써야 합니다. 여기서 '듯'은 '-ㄴ' 뒤에 오는 의존 명사라 앞말과 띄어 씁니다."
      },
      {
        ask: "띄어쓰기가 바르게 된 것은?",
        choices: [
          "건물을 튼튼하게 만 지어라.",
          "그는 그저 웃고 있을뿐이었다.",
          "네가 몇시쯤 도착할 것인지를 알려 줘.",
          "고양이가 집을 나간지 나흘 만에 돌아왔다.",
          "그 상황에서 밥을 먹을 수 있니?"
        ],
        answer: 5,
        explanation: "'먹을 수 있니'는 의존 명사 '수'를 띄어 쓴 바른 표기입니다. ① 튼튼하게만(보조사) ② 있을 뿐이었다(의존 명사) ③ 몇 시쯤(단위 명사) ④ 나간 지(시간의 경과를 뜻하는 의존 명사)."
      }
```
