# 학생에게 내지 않기로 한 문법 문제

선생님이 검토하고 빼낸 문제들입니다.
**지운 것이 아니라 여기로 옮겨 둔 것**이라, 나중에 다시 쓰고 싶으면
아래 내용을 `questions-grammar.js` 의 해당 회차에 도로 붙여 넣으면 됩니다.
