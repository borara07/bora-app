# 표준발음법 문제 소스

문법 05~07회차에 쓴 문제입니다. 영역마다 따로 모아 두었습니다.
회차에 넣을 때 네 영역이 회차마다 골고루 들어가도록 나눴습니다.

원자료는 `문법자료/표준발음-자료.txt` 입니다.

- **쓴 문제** 195개 — 가 45 · 나 50 · 다 50 · 라 50
- **예비 문제** 31개 — 회차에 넣지 않고 남겨 둔 것입니다. 나중에 쓰시면 됩니다.

## 가 영역 — 모음·자음의 발음, 소리의 길이 (제1~7항)


### OX 문제 (20개)

 1. **표준 발음은 표준어의 실제 발음을 기반으로 정한다.**  → **O**  `06회`
    - 맞습니다. 제1항은 표준어의 실제 발음을 따르되 국어의 전통성과 합리성을 고려해 정한다고 밝히고 있습니다.
 2. **표준어의 자음은 19개, 모음은 21개이다.**  → **O**  `07회`
    - 맞습니다. 제2항이 자음 19개, 제3항이 모음 21개를 정하고 있습니다.
 3. **단모음 중에 이중 모음으로 발음할 수 있는 것도 있다.**  → **O**  `05회`
    - 맞습니다. 제4항 [붙임]에 따라 'ㅚ, ㅟ'는 이중 모음으로 발음할 수 있습니다.
 4. **단모음 'ㅚ'를 이중 모음으로 발음하면 [ㅞ]로 발음된다.**  → **O**  `05회`
    - 맞습니다. 반모음 'ㅜ[w]'와 단모음 'ㅔ'를 이어 [ㅞ]로 발음합니다.
 5. **'예, 례'의 'ㅖ'는 [ㅔ]로 발음하는 것을 허용한다.**  → **X**  `07회`
    - 틀립니다. 제5항 다만 2에 따르면 '예, 례' 이외의 'ㅖ'만 [ㅔ]로도 발음합니다.
 6. **'계, 몌, 폐, 혜'의 'ㅖ'는 [ㅔ]로만 발음해야 한다.**  → **X**  `07회`
    - 틀립니다. [ㅖ]가 원칙이고 [ㅔ]로도 발음할 수 있습니다. '계집[계ː집/게ː집]'처럼 둘 다 맞습니다.
 7. **자음을 첫소리로 가지고 있는 음절의 'ㅢ'는 [ㅣ]로 발음한다.**  → **O**  `07회`
    - 맞습니다. 제5항 다만 3의 내용입니다. '무늬[무니], 희망[히망]'처럼 발음합니다.
 8. **자음을 첫소리로 갖지 않은 '의'는 단어의 첫머리에서 [ㅢ]로만 발음한다.**  → **O**  `07회`
    - 맞습니다. '의사[의사], 의자[의자]'처럼 첫머리의 '의'는 반드시 [ㅢ]로 발음합니다.
 9. **단어의 첫음절이 아닌 '의'는 [ㅣ]로도 발음할 수 있다.**  → **O**  `06회`
    - 맞습니다. 제5항 다만 4입니다. '주의[주의/주이]'처럼 둘 다 맞습니다.
10. **조사 '의'는 [ㅔ]로 발음하는 것도 허용한다.**  → **O**  `06회`
    - 맞습니다. '우리의[우리의/우리에]'처럼 발음할 수 있습니다.
11. **국어의 합리성을 고려하여 단모음 'ㅐ'와 'ㅔ'를 구별하지 않고 발음하도록 규정하였다.**  → **X**  `05회`
    - 틀립니다. 전통성을 고려하여 'ㅐ'와 'ㅔ'를 구별하여 발음하도록 정하고 있습니다.
12. **표준 발음법에서 모음의 장단을 구별하는 것은 국어의 전통성을 고려한 것이다.**  → **O**  `05회`
    - 맞습니다. 소리의 길이가 오랫동안 뜻을 가르는 구실을 해 왔기 때문입니다.
13. **긴소리는 단어의 첫음절에서만 나타나는 것을 원칙으로 한다.**  → **O**  `05회`
    - 맞습니다. 제6항입니다. '눈보라[눈ː보라]'는 길지만 '첫눈[천눈]'은 짧습니다.
14. **용언 어간에 피동·사동의 접미사가 붙으면 긴소리가 그대로 유지된다.**  → **X**  `07회`
    - 틀립니다. 짧아집니다. '감다[감ː따] → 감기다[감기다]'처럼 바뀝니다.
15. **용언의 활용형에 나타나는 '져, 쪄, 쳐'는 [저, 쩌, 처]로 발음한다.**  → **O**  `07회`
    - 맞습니다. 제5항 다만 1입니다. '가지어→가져[가저]'처럼 발음합니다.
16. **'ㅑ, ㅒ, ㅕ, ㅖ, ㅘ, ㅙ, ㅛ, ㅝ, ㅞ, ㅠ, ㅢ'는 이중 모음으로 발음한다.**  → **O**  `05회`
    - 맞습니다. 제5항에서 정한 이중 모음 열한 개입니다.
17. **'ㅏ, ㅐ, ㅓ, ㅔ, ㅗ, ㅚ, ㅜ, ㅟ, ㅡ, ㅣ'는 단모음으로 발음한다.**  → **O**  `05회`
    - 맞습니다. 제4항에서 정한 단모음 열 개입니다.
18. **'시계'는 [시계]로만 발음해야 한다.**  → **X**  `06회`
    - 틀립니다. '예, 례' 이외의 'ㅖ'이므로 [시계/시게] 둘 다 맞습니다.
19. **'강의의'는 [강ː이에]로도 발음할 수 있다.**  → **O**  `06회`
    - 맞습니다. 첫음절이 아닌 '의'는 [ㅣ]로, 조사 '의'는 [ㅔ]로도 발음할 수 있습니다.
20. **'떠벌리다'의 첫음절은 긴소리로 발음한다.**  → **X**  `06회`
    - 틀립니다. [떠벌리다]로 짧게 발음합니다. '벌리다[벌ː리다]'와 다릅니다.

### 객관식 (5개)

 1. **다음 중 'ㅢ'의 발음이 바르지 않은 것은?**  → **의사[이사]**  (보기: 늴리리[닐리리] / 무늬[무니] / 희떱다[히떱따] / 의사[이사] / 띄어쓰기[띠어쓰기])  `06회`
    - '의사'는 '의'가 단어의 첫머리에 있고 자음을 첫소리로 갖지 않으므로 [의사]로만 발음합니다.
 2. **다음 중 소리의 길이가 나머지와 다른 것은?**  → **첫눈**  (보기: 눈보라 / 말씨 / 밤나무 / 첫눈 / 멀리)  `05회`
    - '첫눈[천눈]'은 긴소리가 아닙니다. 나머지는 첫음절에서 긴소리로 발음합니다.
 3. **다음 중 'ㅖ'를 [ㅔ]로 발음할 수 없는 것은?**  → **예절**  (보기: 계집 / 시계 / 개폐 / 혜택 / 예절)  `06회`
    - '예, 례'의 'ㅖ'는 [ㅔ]로 발음하지 않습니다. 나머지는 [ㅖ/ㅔ] 둘 다 맞습니다.
 4. **다음 설명 중 표준 발음법에 맞지 않는 것은?**  → **'예, 례'의 'ㅖ'도 [ㅔ]로 발음할 수 있다**  (보기: 'ㅚ, ㅟ'는 이중 모음으로 발음할 수 있다 / 자음 뒤의 'ㅢ'는 [ㅣ]로 발음한다 / 조사 '의'는 [ㅔ]로도 발음할 수 있다 / 첫음절이 아닌 '의'는 [ㅣ]로도 발음할 수 있다 / '예, 례'의 'ㅖ'도 [ㅔ]로 발음할 수 있다)  `07회`
    - '예, 례'의 'ㅖ'는 [ㅔ]로 발음하지 않습니다.
 5. **다음 중 표준 발음이 바른 것은?**  → **희망[히망]**  (보기: 가져[가져] / 쪄[쪄] / 다쳐[다쳐] / 무늬[무늬] / 희망[히망])  `05회`
    - '희망'은 자음 뒤의 'ㅢ'이므로 [히망]입니다. 나머지는 [가저], [쩌], [다처], [무니]로 발음합니다.
