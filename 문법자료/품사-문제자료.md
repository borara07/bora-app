# 품사·용언 문제 소스

문법 **08회(품사)** · **09회(용언의 활용)** 에 쓸 문제입니다.
08회는 `questions-grammar.js` 에 넣었고, 09회는 아직 이 파일에만 있습니다.

원자료는 학원 인쇄물 「문법 [품사] 기본기 테스트」(7쪽) 입니다.
시험지에는 빈칸을 채우는 문제인데, 앱은 보기를 고르는 방식이라 **고르는 문제로 바꿔 적었습니다.**

- 다 쓰면 **108항목** 입니다 (가 10 · 나 20 · 다 34 · 라 14 · 마 30).
- 마 묶음은 한 항목에서 두 문제가 나오므로 실제로는 더 늘릴 수 있습니다.
- 시험지 정답표에서 고치거나 뺀 것은 맨 아래 **[고친 것 · 뺀 것]** 에 적어 두었습니다.

## 가 영역 — 문장에서 품사 가려내기 (원자료 1~10번)

시험지에서는 문장을 단어로 쪼개 표에 품사를 적게 합니다.
앱에서는 **한 단어만 집어서 묻는 5지선다** 로 만들면 됩니다.

> 물음 예 — `다음 문장의 밑줄 친 말의 품사는?`
> 제시문 — `이미 새 교과서를 받은 학생이 매우 많았다. (새)`
> 보기 — 관형사 / 부사 / 명사 / 동사 / 형용사 → 정답 관형사

정답표(원자료 2쪽)를 그대로 옮긴 것입니다.

| 번호 | 문장 | 품사 |
|---|---|---|
| 1 | 나는 어머니께서 주신 밥을 먹었다. | 나(대명사) 는(조사) 어머니(명사) 께서(조사) 주신(동사) 밥(명사) 을(조사) 먹었다(동사) |
| 2 | 그는 몹시 용감한 사람이다. | 그(대명사) 는(조사) 몹시(부사) 용감한(형용사) 사람(명사) 이다(조사) |
| 3 | 우리 반은 자습 시간에 정말 조용하다. | 우리(대명사) 반(명사) 은(조사) 자습(명사) 시간(명사) 에(조사) 정말(부사) 조용하다(형용사) |
| 4 | 이미 새 교과서를 받은 학생이 매우 많았다. | 이미(부사) 새(관형사) 교과서(명사) 를(조사) 받은(동사) 학생(명사) 이(조사) 매우(부사) 많았다(형용사) |
| 5 | 아버지께서 수박 세 통을 사 오셨다. | 아버지(명사) 께서(조사) 수박(명사) 세(관형사) 통(명사) 을(조사) 사(동사) 오셨다(동사) |
| 6 | 첫째도 둘째도 불조심이다. | 첫째(수사) 도(조사) 둘째(수사) 도(조사) 불조심(명사) 이다(조사) |
| 7 | 아차! 내가 지갑을 집에 두고 왔구나. | 아차(감탄사) 내(대명사) 가(조사) 지갑(명사) 을(조사) 집(명사) 에(조사) 두고(동사) 왔구나(동사) |
| 8 | 새 학기에는 정말 공부를 열심히 해야겠다. | 새(관형사) 학기(명사) 에(조사) 는(조사) 정말(부사) 공부(명사) 를(조사) 열심히(부사) 해야겠다(동사) |
| 9 | 나는 친구들과 헤어지고 집으로 돌아왔다. | 나(대명사) 는(조사) 친구들(명사) 과(조사) 헤어지고(동사) 집(명사) 으로(조사) 돌아왔다(동사) |
| 10 | 그 소식을 듣고 철수는 몹시 슬펐다. | 그(관형사) 소식(명사) 을(조사) 듣고(동사) 철수(명사) 는(조사) 몹시(부사) 슬펐다(형용사) |

**물어 볼 만한 단어** (헷갈리는 것만 골랐습니다)
`새`(4·8번, 관형사) · `세`(5번, 관형사) · `그`(2번 대명사 ↔ 10번 관형사) ·
`우리`(3번, 대명사) · `첫째`(6번, 수사) · `아차`(7번, 감탄사) · `열심히`(8번, 부사) ·
`많았다`(4번, 형용사) ↔ `받은`(4번, 동사)

## 나 영역 — 품사 통용 OX (원자료 11~30번)

**그대로 OX 문제로 쓸 수 있습니다.** 앱에서는 `ox: true` 로 넣으면 됩니다.

같은 말이 자리에 따라 품사가 달라지는 것을 묻습니다. 두 문제가 한 쌍입니다.

 1. **‘나도 참을 만큼 참았다.’의 ‘만큼’은 조사이다.** → **X**
    - 꾸미는 말(참을) 뒤에 왔으므로 의존 명사입니다.
 2. **‘나도 너만큼 할 수 있다.’의 ‘만큼’은 명사이다.** → **X**
    - 체언(너) 뒤에 붙었으므로 조사입니다. 앞말에 붙여 씁니다.
 3. **‘어진이는 하나를 배우면 열을 안다.’의 ‘열’은 관형사이다.** → **X**
    - 조사 ‘을’이 붙었으므로 수사입니다.
 4. **‘열 분이나 왔다.’의 ‘열’은 수사이다.** → **X**
    - 뒤의 ‘분’을 꾸미므로 관형사(수 관형사)입니다.
 5. **‘오늘 보라의 표정이 매우 밝다.’의 ‘밝다’는 동사이다.** → **X**
    - 상태를 나타내므로 형용사입니다. ‘밝는다’로 쓸 수 없습니다.
 6. **‘이제 곧 날이 밝는다.’의 ‘밝다’는 형용사이다.** → **X**
    - 날이 밝아 가는 움직임이므로 동사입니다.
 7. **‘오늘은 바람이 아니 분다’의 ‘아니’는 부사이다.** → **O**
    - 서술어 ‘분다’를 꾸미므로 부사입니다.
 8. **‘아니, 이럴 수가!’의 ‘아니’는 감탄사이다.** → **O**
    - 놀람을 나타내며 홀로 쓰였으므로 감탄사입니다.
 9. **‘네가 나보다 낫구나.’의 ‘보다’는 부사이다.** → **X**
    - 체언(나) 뒤에 붙어 견주므로 조사입니다.
10. **‘보다 나은 내일을 위해!’의 ‘보다’는 조사이다.** → **X**
    - ‘나은’을 꾸미므로 부사입니다.
11. **‘학생 일곱이 왔다.’의 ‘일곱’은 수사이다.** → **O**
    - 조사 ‘이’가 붙었으므로 수사입니다.
12. **‘일곱 학생이 왔다.’의 ‘일곱’은 부사이다.** → **X**
    - 뒤의 ‘학생’을 꾸미므로 관형사입니다.
13. **‘그는 학생이다.’의 ‘그’는 명사이다.** → **X**
    - 사람을 대신 가리키므로 대명사입니다.
14. **‘그 학생이 나를 찾아왔다.’의 ‘그’는 명사이다.** → **X**
    - 뒤의 ‘학생’을 꾸미므로 관형사입니다.
15. **‘그는 특별한 능력이 있었다.’의 ‘있다’는 동사이다.** → **X**
    - 가지고 있다는 상태이므로 형용사입니다.
16. **‘우야는 그냥 집에 있었다.’의 ‘있다’는 형용사이다.** → **X**
    - 머무는 움직임이므로 동사입니다. ‘있어라’처럼 시킬 수 있습니다.
17. **‘워니가 빵을 구웠다.’의 ‘굽다’는 형용사이다.** → **X**
    - 불에 익히는 움직임이므로 동사입니다.
18. **‘할머니는 허리가 많이 굽으셨다.’의 ‘굽다’는 동사이다.** → **O**
    - 허리가 휘어 가는 움직임이므로 동사입니다. ‘허리가 굽는다’처럼 쓸 수 있습니다.
    - *시험지 정답표는 X 였으나 O 로 바로잡았습니다.*
19. **‘은지는 키가 아주 컸다.’의 ‘크다’는 동사이다.** → **X**
    - 키가 큰 상태이므로 형용사입니다.
20. **‘수경이는 아주 건강하게 컸다.’의 ‘크다’는 형용사이다.** → **X**
    - 자라는 움직임이므로 동사입니다.

## 다 영역 — 동사인지 형용사인지 (원자료 2~35번, 34개)

**둘 중 고르기** 로 넣습니다. 보기는 `동사` / `형용사` 두 개입니다.

> 물음 예 — `다음 말은 동사입니까, 형용사입니까?`
> 제시문 — `늙다`
> 보기 — 동사 / 형용사 → 정답 동사

| 낱말 | 답 | | 낱말 | 답 | | 낱말 | 답 |
|---|---|---|---|---|---|---|---|
| 어렵다 | 형용사 | | 용감하다 | 형용사 | | 웃다 | 동사 |
| 노력하다 | 동사 | | 운전하다 | 동사 | | 아름답다 | 형용사 |
| 괴롭다 | 형용사 | | 착하다 | 형용사 | | 흐르다 | 동사 |
| 빠르다 | 형용사 | | 높다 | 형용사 | | 늙다 | 동사 |
| 낮다 | 형용사 | | 젊다 | 형용사 | | 만들다 | 동사 |
| 두렵다 | 형용사 | | 푸르다 | 형용사 | | 가볍다 | 형용사 |
| 아프다 | 형용사 | | 느리다 | 형용사 | | 피곤하다 | 형용사 |
| 합격하다 | 동사 | | 자랑하다 | 동사 | | 가냘프다 | 형용사 |
| 떠들다 | 동사 | | 많다 | 형용사 | | 몰려왔다 | 동사 |
| 건강하다 | 형용사 | | 졸다 | 동사 | | 행복하다 | 형용사 |
| 깨끗하다 | 형용사 | | 명랑하다 | 형용사 | | 잘생기다 | 동사 |
| 움찔하다 | 동사 | | | | | | |

**해설을 붙여 줄 만한 것** (학생이 잘 틀리는 것)
- `늙다` · `젊다` — **늙다는 동사, 젊다는 형용사** 입니다. ‘늙는다’는 되지만 ‘젊는다’는 안 됩니다.
- `잘생기다` — 사전에 **동사** 로 올라 있습니다. ‘잘생겼다’처럼 이미 그렇게 된 결과로 씁니다.
- `건강하다`(형용사) ↔ `합격하다`·`운전하다`(동사) — 같은 ‘-하다’라도 갈립니다.
- `빠르다`(형용사) ↔ `흐르다`(동사) — 둘 다 ‘르’로 끝나지만 품사가 다릅니다.
- 가리는 방법 — **‘-는다’를 붙여 보고, ‘-어라’로 시켜 보면 됩니다.** 되면 동사입니다.

## 라 영역 — 본용언인지 보조 용언인지 (원자료 36~50번 중 14개)

**둘 중 고르기** 로 넣습니다. 보기는 `본용언` / `보조 용언` 두 개입니다.

| 문장 | 묻는 말 | 답 |
|---|---|---|
| 미리 밥을 먹어 두었다. | 두다 | 보조 용언 |
| 라면을 끓여 먹었다. | 먹다 | 본용언 |
| 감이 빨갛게 익어 간다. | 가다 | 보조 용언 |
| 시련을 참아 왔다. | 오다 | 보조 용언 |
| 설거지를 하다가 그릇을 깨뜨려 버렸다. | 버리다 | 보조 용언 |
| 외롭게 늙어 간다. | 가다 | 보조 용언 |
| 밥이 다 되어 간다. | 가다 | 보조 용언 |
| 고통을 참아 냈다. | 내다 | 보조 용언 |
| 창문을 열어 놓았다. | 놓다 | 보조 용언 |
| 어머니의 머리를 깎아 드렸다. | 드리다 | 보조 용언 |
| 학생들이 떠들어 댄다. | 대다 | 보조 용언 |
| 아이가 울어 쌓는다. | 쌓다 | 보조 용언 |
| 책을 읽어 드렸다. | 드리다 | 보조 용언 |
| 버스를 놓쳐 버렸다. | 버리다 | 보조 용언 |

**해설로 쓸 말**
- 뒤의 말이 **제 뜻을 잃고 앞말을 도와주기만 하면 보조 용언** 입니다.
- `라면을 끓여 먹었다` 는 끓이고 나서 **정말 먹었으므로** ‘먹다’가 본용언입니다.
- `밥을 먹어 두었다` 의 ‘두다’는 **놓아둔 것이 아니라** 미리 해 놓았다는 뜻만 더합니다.

## 마 영역 — 활용 (원자료 51~80번)

한 항목에서 **문제 두 개** 가 나옵니다.
① 활용형 고르기 (둘 중 고르기) ② 무엇이 바뀌는지 고르기 (둘 중 고르기 또는 5지선다)

> ① `‘(빵을) 굽다’ 에 ‘-어서’를 붙이면?` → 구워서 / 굽어서 → **구워서**
> ② `‘(빵을) 굽다’ 의 활용은?` → ㅂ 불규칙 / ㅂ 규칙 → **ㅂ 불규칙**

| 기본형 | 활용형 | 구분 |
|---|---|---|
| (불을) 끄다 | 꺼서 | ‘으’ 탈락 |
| (물을) 따르다 | 따라서 | ‘으’ 탈락 |
| (손을) 씻다 | 씻어서 | ㅅ 규칙 |
| (두 점을) 잇다 | 이어서 | ㅅ 불규칙 |
| 일컫다 (무엇이라고 부르다) | 일컬어서 | ㄷ 불규칙 |
| 묻다 (질문하다) | 물어서 | ㄷ 불규칙 |
| 묻다 (매장하다) | 묻어서 | ㄷ 규칙 |
| (풀이) 돋다 | 돋아서 | ㄷ 규칙 |
| (물을) 쏟다 | 쏟아서 | ㄷ 규칙 |
| (밤을) 줍다 | 주워서 | ㅂ 불규칙 |
| (남을) 돕다 | 도와서 | ㅂ 불규칙 |
| (날이) 덥다 | 더워서 | ㅂ 불규칙 |
| (얼굴이) 아름답다 | 아름다워서 | ㅂ 불규칙 |
| (빵을) 굽다 | 구워서 | ㅂ 불규칙 |
| (허리가) 굽다 | 굽어서 | ㅂ 규칙 |
| (풀을) 뽑다 | 뽑아서 | ㅂ 규칙 |
| (음식을) 나르다 | 날라서 | ‘르’ 불규칙 |
| (물이) 흐르다 | 흘러서 | ‘르’ 불규칙 |
| (시험을) 치르다 | 치러서 | ‘르’ 규칙 |
| (정상에) 다다르다 | 다다라서 | ‘르’ 규칙 |
| (도서관에) 들르다 | 들러서 | ‘르’ 규칙 |
| 이르다 (도달하다) | 이르러서 | ‘러’ 불규칙 |
| 이르다 (빠르다) | 일러서 | ‘르’ 불규칙 |
| 멀다 (‘-ㄴ’을 붙임) | 먼 | ‘ㄹ’ 탈락 |
| 사랑하다 | 사랑하여서 | ‘여’ 불규칙 |
| 푸르다 | 푸르러서 | ‘러’ 불규칙 |
| 까맣다 | 까매서 | ㅎ 불규칙 |
| 누렇다 | 누레서 | ㅎ 불규칙 |
| 하얗다 | 하얘서 | ㅎ 불규칙 |
| 밥을 잘 **저어** 주세요 (기본형 묻기) | 젓다 | ㅅ 불규칙 |

**꼭 짝지어 낼 것** (뜻에 따라 갈리는 것)
- `묻다` — 질문하면 **물어서**(불규칙), 땅에 묻으면 **묻어서**(규칙)
- `굽다` — 빵은 **구워서**(불규칙), 허리는 **굽어서**(규칙)
- `이르다` — 도달하면 **이르러서**(러 불규칙), 빠르면 **일러서**(르 불규칙)
- `치르다`·`들르다`·`다다르다` 는 ‘르’로 끝나도 **규칙** 입니다. 학생이 가장 많이 틀립니다.

## [고친 것 · 뺀 것]

원장님이 정해 주신 대로 손봤습니다.

**① 고침 — ‘할머니는 허리가 많이 굽으셨다.’의 ‘굽다’ (나 영역 18번)**

시험지 정답표는 `X` 였으나 **`O` 로 바로잡았습니다.**
‘한쪽으로 휘다’ 뜻의 ‘굽다’는 동사입니다. ‘허리가 굽는다’처럼 쓸 수 있습니다.
앞 문항(17번 ‘빵을 굽다’)과 함께 **둘 다 동사** 라는 것을 확인시켜 주는 짝이 되었습니다.

**② 뺌 — 동사/형용사 1번**

정답표에는 답(형용사)만 있고 **문제의 낱말이 인쇄물에 없어서** 뺐습니다.
다 영역은 35개에서 **34개** 가 되었습니다.
나중에 원본을 보시고 낱말을 알려 주시면 그때 넣겠습니다.

**③ 뺌 — ‘친구에게 사과를 깎아 주었다.’의 ‘주다’ (라 영역 2번)**

‘깎아서 건네주었다’로도, ‘친구를 위해 깎아 주었다’로도 읽혀 답이 하나로 정해지지 않아 뺐습니다.
라 영역은 15개에서 **14개** 가 되었습니다.

**④ 오타 고침**

- ‘까맣다까맣다’ → **‘까맣다’** (활용형 ‘까매서’, ㅎ 불규칙은 그대로)
- ‘치르다·들르다·다다르다’를 `르 규칙` 으로 적은 것은 **그대로 두었습니다.**
  엄밀히는 ‘으’ 탈락이지만 학교 문법 교재도 대부분 이렇게 쓰고,
  ‘르 불규칙이 아니다’ 라는 것이 이 문제의 핵심이라 학생에게 오히려 분명합니다.

### 한 가지 봐 주실 것 — OX 20문제의 답이 O 4개 · X 16개 입니다

시험지가 '틀린 설명 찾기' 로 만들어져 있어서 그렇습니다.
