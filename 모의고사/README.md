# 모의고사 성적표 (엑셀)

매주 보는 국어 모의고사 성적표를 엑셀 한 파일로 냅니다.
회차마다 새 시트를 만들지 않고, **`회차설정` 시트만 고쳐서** 계속 씁니다.

`모의고사-성적표-30차.xlsx` — 30차 심화모의고사의 정답·배점·영역·등급컷이 이미 들어 있습니다.
(등급컷: 화법과 작문 95-88-77-64 / 언어와 매체 92-85-74-62)

## 쓰는 순서

1. **회차설정** — 시험 이름 · 시행일 · 등급컷, 영역 표(어느 문항이 어느 영역인지),
   문항별 정답·배점을 답지 보고 적습니다.
   맨 위 `확인` 칸에 **정상입니다**가 떠야 합니다.
   (배점 합계가 100점인지, 영역 표가 45문항을 빠짐없이 한 번씩 덮는지 스스로 검사합니다)
2. **답안입력** — 한 줄에 학생 한 명. 이름 · 학년 · 선택과목을 적고 1~45번 답을 적습니다.
   `한 번에 입력` 칸에 45자리를 이어 붙여 넣어도 됩니다.
   선택과목(화법과 작문 / 언어와 매체)에 따라 35~45번이 알아서 다른 정답표로 채점됩니다.
3. **성적표** — 이름을 골라 한 명씩 보고 인쇄합니다. A4 한 장입니다.
   학원 로고 · 연보라 톤 · 영역별 막대그래프가 들어갑니다.
   글꼴은 **나눔스퀘어라운드** 하나로, 표 안의 글자는 모두 11pt로 맞췄습니다.
   (점수·등급·제목만 일부러 크게 씁니다. 글꼴이 없는 컴퓨터에서는 기본 글꼴로 바뀝니다)
   A4 한 장에 들어가도록 줄 높이와 여백(좌우 0.55″ · 위아래 0.6″)을 맞춰 두었습니다.
   **인쇄는 쪽 가운데 맞춤**으로 켜 두었습니다. 프로그램마다 인쇄 배율이 달라도
   위아래 여백이 저절로 같아집니다.
4. **성적표(전원)** — 학생마다 쪽이 나뉘어 있어 한 번에 전원 인쇄됩니다.
   인쇄할 쪽수는 `분석` 시트에 적혀 있습니다.
5. **분석** — 응시 인원 · 평균 · 등급 분포 · 문항별 정답률 · 공통과목 영역별 반 평균.

성적표의 영역 칸은 **11개**입니다. 한 선택과목의 영역이 11개를 넘으면
`회차설정`의 `확인` 칸이 알려 줍니다.

`자동계산` · `전체채점` 시트는 계산용입니다. 고치지 마십시오.
`로고-성적표.png` 는 `logo/logo-h.png` 를 성적표 크기로 줄여 둔 것입니다.
`회차설정` 시트에 줄을 끼워 넣거나 지우면 자리가 밀려 다른 시트가 엉뚱한 칸을 봅니다.
칸의 **값만** 고쳐 쓰십시오.

## 지난 수기 시트에 있던 오류

전에 쓰던 회차별 시트에는 복사하면서 생긴 계산 오류가 네 곳 있었습니다.
이 파일은 같은 오류가 나지 않게 만들었습니다.

| 지난 시트 | 이 파일 |
|---|---|
| 갈래복합 성취도가 118%로 나옴 (배점 11점, 더한 칸은 13점) | 배점을 문항 배점에서 자동으로 더해서 어긋날 수 없음 |
| 현대소설 득점이 고전소설과 같은 칸을 더함 | 영역 표의 시작·끝 번호로만 더함 |
| 고전시가 배점 9점, 더한 칸은 7점 | 위와 같음 |
| 등급컷 표시는 90-84-76-62인데 계산은 90/80/70/60 | 적어 넣은 등급컷 그대로 계산 |

영역 표가 문항을 빠뜨리거나 겹치면 `회차설정`의 `확인` 칸과 성적표에 경고가 뜹니다.

## 파일 다시 만들기

`성적표-엑셀-만들기.py` 가 이 엑셀을 만드는 스크립트이고,
`30차-정답.py` 에 30차 정답·배점·영역이 들어 있습니다.

```
pip install openpyxl
python3 성적표-엑셀-만들기.py
```

다음 회차는 엑셀의 `회차설정` 시트를 고치면 되므로, 보통은 스크립트를 다시 돌릴 일이 없습니다.
