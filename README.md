# 고등 국어 어휘 테스트 웹앱

학생이 이름을 입력하고 4지선다 문제를 한 문제씩 풀면,
마지막에 점수와 틀린 문제 해설을 보여주는 웹앱입니다.
휴대폰 화면에 맞춰져 있습니다.

**여러 회차**를 담을 수 있습니다. 앱을 열면 먼저 회차를 고르는 화면이 나오고,
회차를 고르면 그 회차 문제만 출제됩니다.

현재 들어 있는 회차는 **01회 논리 1**
(「어휘력이 독해력이다」 01회 논리 1 / 수능필수 한자성어: 삶의 이치)
하나이며, 어휘 30개(논리 어휘 24개 + 한자성어 6개) 중 **매번 10개가 무작위로** 출제됩니다.

**설치할 프로그램은 없습니다.** 파일을 열기만 하면 바로 실행됩니다.

---

## 1. 실행하는 방법

### 방법 A. 내 컴퓨터에서 바로 열기 (가장 쉬움)

1. 이 폴더의 파일 4개를 한 폴더에 모두 내려받습니다.
   (`index.html`, `style.css`, `app.js`, `questions.js` — **4개가 같은 폴더에 있어야 합니다**)
2. `index.html` 파일을 **더블클릭**합니다.
3. 인터넷 브라우저(크롬, 엣지 등)가 열리면서 테스트가 시작됩니다.

### 방법 B. 학생들이 휴대폰으로 접속하게 하기 (GitHub Pages)

1. GitHub에서 이 저장소(`bora-app`) 페이지를 엽니다.
2. 위쪽 메뉴에서 **Settings**(설정)를 누릅니다.
3. 왼쪽 목록에서 **Pages**를 누릅니다.
4. `Branch` 항목에서 **main**을 고르고, 폴더는 `/ (root)` 그대로 둔 뒤 **Save**를 누릅니다.
5. 1~2분 기다린 뒤 새로고침하면 주소가 하나 나옵니다.
   (예: `https://borara07.github.io/bora-app/`)
6. 이 주소를 학생들에게 보내주면 휴대폰에서 바로 풀 수 있습니다.

> 참고: 5번의 주소가 나오려면 파일이 `main` 브랜치에 있어야 합니다.

## 2. 회차와 문제를 바꾸는 방법

**`questions.js` 파일 하나만 고치면 됩니다.** 다른 파일은 건드리지 않아도 됩니다.
파일 맨 위에 고치는 방법이 자세히 적혀 있습니다.

### 파일의 구조

```
ROUNDS ─┬─ 01회 ─┬─ 문제 1
        │        ├─ 문제 2
        │        └─ ...
        └─ 02회 ─┬─ 문제 1
                 └─ ...
```

### 회차를 새로 추가하려면

`questions.js` 아래쪽의 **`▼▼▼ 여기에 새 회차를 추가하세요 ▼▼▼`** 를 찾으세요.
바로 아래에 붙여넣을 틀이 준비되어 있습니다.
각 줄 맨 앞의 빗금 두 개(`//`)만 지우면 그대로 살아납니다.

```js
{
  title: "02회 논리 2",           // 회차 선택 화면에 크게 보일 이름
  subtitle: "논리 어휘 20개",     // 그 아래 작게 보일 설명 (없으면 "")
  questions: [
    ... 문제들 ...
  ]
},
```

저장하고 새로고침하면 **회차 선택 화면에 자동으로 나타납니다.**

### 문제 하나의 형식

`questions.js`를 메모장(윈도우) 또는 텍스트 편집기(맥)로 열면 아래와 같은 부분이 반복됩니다.

```js
  {
    word: "도출",
    hanja: "導出",
    choices: [
      "다른 것에 영향을 받아 어떤 현상이 나타남",
      "판단이나 결론 등을 이끌어 냄",
      "모자라거나 부족한 것을 보충하여 완전하게 함",
      "둘 사이에서 양편의 관계를 맺어 줌"
    ],
    answer: 2,
    explanation: "이끌어[導] 냄[出]. 예) ... 〈24모의〉"
  },
```

| 항목 | 뜻 | 주의할 점 |
|---|---|---|
| `word` | 화면에 크게 보여줄 어휘 | |
| `hanja` | 어휘 아래 작게 보여줄 한자 | 필요 없으면 `""` 로 비워두세요 |
| `choices` | 보기 4개 | **반드시 4개** |
| `answer` | 정답이 몇 번째 보기인지 | **1, 2, 3, 4 중 하나** (첫 번째 보기가 정답이면 `1`) |
| `explanation` | 틀렸을 때 보여줄 해설 | 비워둬도 됩니다 |

### 문제를 추가하려면

`{` 부터 `},` 까지 한 덩어리를 통째로 복사해서 아래에 붙여넣고 내용만 바꾸세요.

### 문제 수를 바꾸려면

`questions.js` 맨 위의 이 부분을 고치세요.

```js
var QUIZ_LENGTH = 10;                       /* 한 번에 낼 문제 수 */
var QUIZ_TITLE = "고등 국어 어휘 테스트";      /* 화면 맨 위 제목 */
var QUIZ_QUESTION_LABEL = "다음 어휘의 뜻으로 알맞은 것은?";   /* 문제 위 안내 문구 */
```

> `QUIZ_LENGTH` 는 **모든 회차에 함께 적용됩니다.**
> 지금은 01회에 문제 30개가 들어 있고 `QUIZ_LENGTH = 10` 이라서
> **매번 30개 중 10개가 무작위로 출제됩니다.** (보기 순서도 매번 섞입니다.)
> 회차 문제를 전부 풀게 하려면 숫자를 크게(예: `100`) 적어두면 됩니다.
> 회차에 든 문제가 그보다 적으면 있는 만큼만 출제됩니다.

### 고칠 때 자주 하는 실수

- 큰따옴표 `"` 를 빠뜨림 → 글자는 항상 `"` 로 감싸야 합니다.
- 각 줄 끝의 쉼표 `,` 를 빠뜨림
- 보기를 3개나 5개만 적음 → 반드시 4개
- 뜻 안에 큰따옴표를 씀 → 작은따옴표 `'` 를 쓰세요.

무언가 잘못되면 화면에 **"문제 파일을 확인해주세요"** 라는 안내와 함께
몇 번째 문제가 잘못됐는지 알려줍니다. 그 부분만 고치면 됩니다.

## 3. 파일 설명

| 파일 | 역할 | 고쳐도 되나요? |
|---|---|---|
| `questions.js` | **문제와 해설** | ✅ 여기만 고치면 됩니다 |
| `index.html` | 화면 구조 | 건드리지 않아도 됩니다 |
| `style.css` | 색깔·글씨 크기 | 원하면 색만 바꿔도 됩니다 |
| `app.js` | 채점·화면 전환 등 동작 | 건드리지 마세요 |
| `samples/questions-english-sample.js` | 영어 어휘 예시 문제 (참고용) | 쓰지 않으면 그냥 두세요 |
| `CLAUDE.md` | 디자인 톤 등 개발 규칙 메모 | 건드리지 않아도 됩니다 |

> 영어 어휘 문제는 `samples/questions-english-sample.js` 에 있습니다.
> 회차로 넣고 싶다면 그 안의 문제들을 새 회차의 `questions` 안에 붙여넣으세요.

## 4. 지금 들어 있는 기능

- **회차 선택 화면** (회차마다 이름·설명·문제 수 표시)
- 학생 이름 입력 후 시작 (이름을 안 쓰면 시작되지 않습니다)
- 한 화면에 **한 문제씩**, 4지선다
- 위쪽에 `3 / 10` 진행 표시와 진행 막대
- 보기를 골라야 "다음 문제" 버튼이 켜집니다
- 마지막 문제에서는 버튼이 "결과 보기"로 바뀝니다
- 결과 화면: 점수, 정답률, 격려 문구
- **틀린 문제만** 모아서 `내 답 / 정답 / 해설` 표시
- "이 회차 다시 풀기" / "다른 회차 고르기" 버튼
  (다시 풀면 문제와 보기 순서가 새로 섞입니다)
- 어휘 아래 한자 표시 (`hanja` 를 비워두면 표시되지 않습니다)
- 연보라 계열 색과 큰 글씨로 휴대폰에서 읽기 편하게 구성
  (어두운 화면 설정에서도 잘 보입니다)
