# 고등 국어 어휘 테스트 웹앱

학생이 이름을 입력하고 4지선다 문제를 한 문제씩 풀면,
마지막에 점수와 틀린 문제 해설을 보여주는 웹앱입니다.
휴대폰 화면에 맞춰져 있습니다.

**여러 회차**를 담을 수 있습니다. 앱을 열면 먼저 회차를 고르는 화면이 나오고,
회차를 고르면 그 회차 문제만 출제됩니다.

## 1. 실행하는 방법

### 방법 A. 내 컴퓨터에서 바로 열기 (가장 쉬움)

1. 이 폴더의 파일 4개를 한 폴더에 모두 내려받습니다.
   (`index.html`, `style.css`, `app.js`, `questions.js` — **4개가 같은 폴더에 있어야 합니다**)
2. `index.html` 파일을 **더블클릭**합니다.
3. 인터넷 브라우저(크롬, 엣지 등)가 열리면서 테스트가 시작됩니다.

### 방법 B. 학생들이 휴대폰으로 접속하게 하기 (GitHub Pages)

1. GitHub에서 이 저장소(`bora-app`) 페이지를 엽니다.
2. 위쪽 메뉴에서 **Settings**(설정)를 누릅니다.
3. 왼쪽 목록에서 **Pages**를 누릅니다.
4. `Branch` 항목에서 **main**을 고르고, 폴더는 `/ (root)` 그대로 둔 뒤 **Save**를 누릅니다.
5. 1~2분 기다린 뒤 새로고침하면 주소가 하나 나옵니다.
   (예: `https://borara07.github.io/bora-app/`)
6. 이 주소를 학생들에게 보내주면 휴대폰에서 바로 풀 수 있습니다.

> 참고: 5번의 주소가 나오려면 파일이 `main` 브랜치에 있어야 합니다.

## 2. 회차와 문제를 바꾸는 방법

**`questions.js` 파일 하나만 고치면 됩니다.** 다른 파일은 건드리지 않아도 됩니다.
파일 맨 위에 고치는 방법이 자세히 적혀 있습니다.

### 파일의 구조

```
ROUNDS ─┬─ 01회 ─┬─ 문제 1
        │        ├─ 문제 2
        │        └─ ...
        └─ 02회 ─┬─ 문제 1
                 └─ ...
```

### 회차를 새로 추가하려면

`questions.js` 아래쪽의 **`▼▼▼ 여기에 새 회차를 추가하세요 ▼▼▼`** 를 찾으세요.
바로 아래에 붙여넣을 틀이 준비되어 있습니다.
각 줄 맨 앞의 빗금 두 개(`//`)만 지우면 그대로 살아납니다.

```js
{
  title: "02회 논리 2",           // 회차 선택 화면에 크게 보일 이름
  subtitle: "논리 어휘 20개",     // 그 아래 작게 보일 설명 (없으면 "")
  questions: [
    ... 문제들 ...
  ]
},
```

저장하고 새로고침하면 **회차 선택 화면에 자동으로 나타납니다.**

### 문제 하나의 형식

`questions.js`를 메모장(윈도우) 또는 텍스트 편집기(맥)로 열면 아래와 같은 부분이 반복됩니다.

```js
  {
    word: "도출",
    hanja: "導出",
    choices: [
      "다른 것에 영향을 받아 어떤 현상이 나타남",
      "판단이나 결론 등을 이끌어 냄",
      "모자라거나 부족한 것을 보충하여 완전하게 함",
      "둘 사이에서 양편의 관계를 맺어 줌"
    ],
    answer: 2,
    explanation: "이끌어[導] 냄[出]. 예) ... 〈24모의〉"
  },
```

| 항목 | 뜻 | 주의할 점 |
|---|---|---|
| `word` | 화면에 크게 보여줄 어휘 | |
| `hanja` | 어휘 아래 작게 보여줄 한자 | 필요 없으면 `""` 로 비워두세요 |
| `choices` | 보기 4개 | **반드시 4개** |
| `answer` | 정답이 몇 번째 보기인지 | **1, 2, 3, 4 중 하나** (첫 번째 보기가 정답이면 `1`) |
| `explanation` | 틀렸을 때 보여줄 해설 | 비워둬도 됩니다 |

> **해설 안에 `예)` 를 쓰면 그 뒤는 예문 상자로 따로 표시됩니다.**
> `유래)` 라고 쓰면 `유래` 딱지가 붙습니다.
> 뜻이 여러 개일 때 `①` `②` 앞에 띄어쓰기를 두면 줄이 나뉘어 보입니다.

### 문제를 추가하려면

`{` 부터 `},` 까지 한 덩어리를 통째로 복사해서 아래에 붙여넣고 내용만 바꾸세요.

### 문제 수를 바꾸려면

`questions.js` 맨 위의 이 부분을 고치세요.

```js
var QUIZ_LENGTH = 15;                       /* 한 번에 낼 문제 수 */
var IDIOM_COUNT = 3;                        /* 그중 한자성어 개수 */
var QUIZ_TITLE = "고등 국어 어휘 테스트";      /* 화면 맨 위 제목 */
var QUIZ_QUESTION_LABEL = "다음 어휘의 뜻으로 알맞은 것은?";   /* 문제 위 안내 문구 */
```

### 한자성어를 꼭 넣기

문제에 `type: "한자성어"` 라고 적어두면 한자성어로 취급합니다.

```js
{
  word: "권선징악",
  hanja: "勸善懲惡",
  type: "한자성어",        ← 이 줄이 있으면 한자성어
  ...
}
```

매 회차마다 이 표시가 붙은 문제들 중에서 `IDIOM_COUNT` 개수만큼 먼저 뽑고,
나머지는 일반 어휘로 채웁니다. 회차에 한자성어가 그보다 적으면 있는 만큼만 넣습니다.

> `QUIZ_LENGTH` 와 `IDIOM_COUNT` 는 **모든 회차에 함께 적용됩니다.**
> 지금은 01회에 문제 30개가 들어 있고 `QUIZ_LENGTH = 15` 라서
> **매번 30개 중 15개가 무작위로 출제됩니다.** (보기 순서도 매번 섞입니다.)
> 회차 문제를 전부 풀게 하려면 숫자를 크게(예: `100`) 적어두면 됩니다.
> 회차에 든 문제가 그보다 적으면 있는 만큼만 출제됩니다.

### 고칠 때 자주 하는 실수

- 큰따옴표 `"` 를 빠뜨림 → 글자는 항상 `"` 로 감싸야 합니다.
- 각 줄 끝의 쉼표 `,` 를 빠뜨림
- 보기를 3개나 5개만 적음 → 반드시 4개
- 뜻 안에 큰따옴표를 씀 → 작은따옴표 `'` 를 쓰세요.

무언가 잘못되면 화면에 **"문제 파일을 확인해주세요"** 라는 안내와 함께
몇 번째 문제가 잘못됐는지 알려줍니다. 그 부분만 고치면 됩니다.

## 4. 점수 기록

테스트를 끝내면 **이름 · 학교 · 회차 · 점수 · 정답률 · 날짜 · 문항별 정오답**이 저장됩니다.
학생이 같은 이름·학교·전화 뒷자리로 다시 들어오면 `내 지난 기록 보기` 에서 자기 기록만 볼 수 있습니다.

기록은 **학생이 쓰는 기기(브라우저)에 저장됩니다.**
따라서 학생이 다른 휴대폰으로 들어가면 이전 기록이 보이지 않습니다.
모든 학생 기록을 한곳에 모으려면 아래 수파베이스 설정을 해주세요.

### 점수를 수파베이스에 쌓기

**1단계.** 수파베이스에서 프로젝트를 만들고, `SQL Editor` 에 아래를 붙여넣어 실행합니다.
(이 저장소의 **`supabase-설정.sql`** 파일 내용과 같습니다. 그 파일을 열어 복사하셔도 됩니다.)

```sql
create table public.quiz_attempts (
  id           bigint generated always as identity primary key,
  student_name text        not null,
  school       text        not null,
  phone4       text        not null,
  round_title  text        not null,
  correct      int         not null,
  total        int         not null,
  percent      int         not null,
  items        jsonb       not null,   -- 출제된 문제와 학생이 고른 답
  taken_at     timestamptz not null,
  created_at   timestamptz not null default now()
);

-- 앱은 기록을 '넣기만' 할 수 있고, 남의 기록을 읽지는 못하게 합니다
alter table public.quiz_attempts enable row level security;

create policy "앱에서 기록 추가만 허용"
  on public.quiz_attempts for insert to anon with check (true);
```

**2단계.** 수파베이스 `Settings → API` 에서 **Project URL** 과 **anon public** 키를 복사합니다.

**3단계.** `storage.js` 맨 위의 두 칸을 채웁니다.

```js
var SUPABASE = {
  url: "https://여기에프로젝트주소.supabase.co",
  anonKey: "여기에anon키",
  table: "quiz_attempts"
};
```

이렇게 하면 학생이 시험을 끝낼 때마다 기록이 수파베이스로 전송됩니다.
인터넷이 끊겨 전송에 실패해도 기기에 남아 있다가, **다음에 앱을 열 때 자동으로 다시 보냅니다.**

> ⚠️ **개인정보 주의**
> 이 표에는 학생 이름·학교·학부모님 전화번호 뒷자리가 들어갑니다.
> 위 SQL은 **넣기(insert)만 허용하고 읽기(select)는 막아 두었습니다.**
> 학생이 남의 기록을 볼 수 없게 하려면 이 설정을 그대로 두시고,
> 기록은 수파베이스 화면에 로그인해서 확인하세요.
> 읽기 권한을 열면 앱에 접속한 누구나 전체 명단을 볼 수 있게 됩니다.

## 5. 이번 주 숙제 회차 정하기

학생에게 **이번 주에 풀 회차 하나만** 보이게 할 수 있습니다.

선생님용 화면 맨 위 **`이번 주 숙제`** 칸에서 회차를 고르고 `이 회차로 정하기` 를 누르면 됩니다.

- 학생 화면에는 **그 회차 하나만** 나타납니다. 다른 회차는 아예 보이지 않습니다
- 같은 회차는 **몇 번이든 다시 풀 수 있습니다** (`이 회차 다시 풀기`)
- 다음 주에 다시 와서 회차만 바꾸면 됩니다
- `모든 회차 열기` 를 고르면 학생이 아무 회차나 고를 수 있습니다

처음 한 번은 `SQL Editor` 에서 **`supabase-숙제회차.sql`** 을 실행해두어야 합니다.
실행하기 전에는 학생에게 모든 회차가 보입니다.

> 학생 휴대폰이 잠시 인터넷이 안 되면, **지난번에 확인한 숙제 회차**를 그대로 씁니다.

## 6. 선생님용 화면

학생 화면과 **완전히 다른 주소**입니다.

```
학생용    https://borara07.github.io/bora-app/
선생님용  https://borara07.github.io/bora-app/teacher.html
```

**학생 화면에는 선생님용으로 들어가는 통로가 전혀 없습니다.**
위의 `teacher.html` 주소를 즐겨찾기에 넣어두고 쓰세요.
비밀번호를 넣어야 열리고, 맞으면 **모든 학생의 기록**을 볼 수 있습니다.

- 전체 요약 (학생 수, 시험 횟수, 평균 정답률)
- **회차별 평균** (회차 / 인원 / 응시 횟수 / 평균)
- **학생별 누적** (이름 / 학교 / 응시 횟수 / 평균 / 최근 응시일)
- **전체 기록** (한 줄에 시험 하나씩)
- **엑셀(CSV)로 내려받기**

표의 **제목 칸을 누르면 그 기준으로 정렬**됩니다. 한 번 더 누르면 반대 순서가 됩니다.

### 비밀번호 정하기 (한 번만)

수파베이스 `SQL Editor` 에 **`supabase-선생님.sql`** 내용을 붙여넣고 실행하세요.
그 안에 이런 줄이 있습니다. **이 한 줄만** 원하시는 비밀번호로 바꾸시면 됩니다.

```sql
values (1, '바꿀비밀번호')                     -- ★ 여기만 고치세요 ★
```

> **비밀번호는 앱 파일 어디에도 저장되지 않습니다.**
> 수파베이스에만 저장되고, 입력할 때마다 서버에서 맞는지 확인합니다.
> 그래서 학생이 앱 파일을 들여다봐도 비밀번호를 알아낼 수 없습니다.

나중에 비밀번호를 바꾸려면 `SQL Editor` 에서 아래 한 줄만 실행하세요.

```sql
update public.admin_secret set password = '새비밀번호' where id = 1;
```

### 이 설정을 하기 전에는

선생님용 화면은 열리지만 **그 기기에 저장된 기록만** 보입니다.
그때 쓰는 임시 비밀번호는 `storage.js` 맨 위의 `TEACHER_PASSWORD` 에 있습니다.
(처음 값은 `bora2026` 이며, 바꾸셔도 됩니다.)

## 7. 재원생 명단과 연결하기

시트에 있는 재원생 명단(이름 / 학부모 연락처 / 학생 연락처 / 학교)을 수파베이스에 넣어두면,
학생이 시험을 볼 때마다 **명단의 누구인지 자동으로 찾아 성적을 누적**합니다.
아직 한 번도 시험을 안 본 학생도 한눈에 보입니다.

### 1단계. 표 만들기 (한 번만)

수파베이스 `SQL Editor` 에 **`supabase-학생명단.sql`** 내용을 붙여넣고 실행하세요.
고칠 곳은 없습니다.

### 2단계. 시트를 CSV로 저장

구글 시트에서 **파일 → 다운로드 → 쉼표로 구분된 값(.csv)** 을 누릅니다.

### 3단계. 수파베이스에 올리기

1. 수파베이스 왼쪽 **`Table Editor`**
2. 표 목록에서 **`students`** 를 고릅니다
3. 가운데 **`CSV에서 데이터를 가져오기`** 를 누르고 방금 받은 파일을 올립니다
4. 시트의 각 칸을 아래와 같이 연결해 주세요

| 시트의 칸 | 수파베이스의 칸 |
|---|---|
| 이름 | `name` |
| 학교 | `school` |
| 학부모 연락처 | `parent_phone` |
| 학생 연락처 | `student_phone` |

> `id`, `name_key`, `parent_phone4`, `created_at` 은 **비워두세요.** 자동으로 채워집니다.

### 4단계. 그동안 쌓인 기록 연결하기

명단을 넣은 뒤 `SQL Editor` 에서 아래 한 줄을 실행하면,
명단을 넣기 전에 학생들이 본 시험도 전부 연결됩니다.

```sql
select public.match_all_attempts();
```

나중에 학생을 추가하거나 이름을 고친 뒤에도 이 한 줄을 다시 실행하시면 됩니다.

### 무엇을 기준으로 같은 학생이라고 보나요

**이름 + 학부모 연락처 뒷 4자리** 입니다.

- 이름의 띄어쓰기는 무시합니다 (`최 지 후` = `최지후`)
- 학부모 연락처는 `010-1234-5678` 이든 `01012345678` 이든 상관없습니다
- **학교는 기준으로 쓰지 않습니다.** 학생이 `보라고` 라고 쓰고 시트에는 `보라고등학교` 라고
  적혀 있어도 같은 학생으로 연결됩니다
- 학생 연락처는 명단에 보관만 하고, 학생을 찾는 데는 쓰지 않습니다
  (학생이 앱에서 입력하지 않는 정보이기 때문입니다)

### 명단에 있는 학생만 시험을 볼 수 있습니다

앱 주소를 아는 사람이면 누구나 시험을 볼 수 있으면 곤란하니,
**재원생 명단에 있는 학생만** 시작할 수 있게 막아 두었습니다.

- 처음 한 번은 `SQL Editor` 에서 **`supabase-재원생확인.sql`** 을 실행해두어야 합니다
- 학생이 `테스트 시작` 을 누르면, 적어 넣은 **이름 + 학부모님 전화번호 뒷 4자리** 가
  명단과 맞는지 서버에 물어봅니다. 맞을 때만 문제가 나옵니다
- 명단에 없으면 *"재원생 명단에서 찾지 못했습니다"* 라고 안내하고 시작되지 않습니다
- 퇴원한 학생(`active` 가 꺼진 학생)도 시작할 수 없습니다
- **명단 자체는 학생 화면으로 절대 내려가지 않습니다.** 맞다/아니다만 오갑니다
- 앱 화면뿐 아니라 **서버에서도 한 번 더 막습니다.**
  명단에 없는 사람의 기록은 아예 저장되지 않습니다

> 인터넷이 안 되면 재원생인지 확인할 수 없으므로 시험도 시작되지 않습니다.
> *"인터넷 연결을 확인한 뒤 다시 눌러주세요"* 라고 안내합니다.

> 선생님이 직접 앱을 써 보시려면, 선생님 이름도 명단(`students`)에 넣어두셔야 합니다.

### 이름을 잘못 쓴 학생 찾기

학생이 이름이나 번호를 잘못 입력하면 명단에서 못 찾습니다.
그런 기록은 `SQL Editor` 에서 아래로 확인할 수 있습니다.

```sql
select * from public.unmatched_attempts;
```

수파베이스 `Table Editor` 에서 그 기록의 이름이나 번호를 고친 뒤
`select public.match_all_attempts();` 를 실행하면 연결됩니다.

### 선생님용 화면에서 보기

명단을 넣어두면 선생님용 화면에 **`재원생 기준 누적`** 이 새로 생깁니다.

- `재원생 90명 중 19명 응시 · 아직 안 본 학생 71명` 처럼 전체 요약
- **학년별 응시 상황** (학년 / 인원 / 응시 / 아직 / 평균)
- 학생 한 명씩의 누적 (아직 안 본 학생은 `아직 안 봄` 으로 표시)

학년은 `memo` 에 적은 반 이름의 앞부분에서 자동으로 뽑습니다.
(`고2 오후 · 25기` → `고2`) 반 이름을 바꾸시면 학년 구분도 그에 따라 바뀝니다.

## 8. 시트가 바뀌었을 때 명단 맞추기

구글 시트의 **`재원생` 탭**이 바뀌면 앱의 명단도 맞춰야 합니다.

### 어떻게 처리되나

| 시트에서 | 앱에서는 |
|---|---|
| 학생이 새로 추가됨 | 재원생으로 **추가** |
| 학생이 사라짐 | 재원생에서 **내려감** (앱 화면에서 안 보임) |
| 사라졌던 학생이 다시 나타남 | 재원생으로 **복귀** |

**학생을 지우지 않습니다.** 재원생에서 내려가도 그동안의 시험 기록은 수파베이스에 그대로 남고,
`former_students` 로 따로 모아서 볼 수 있습니다.

```sql
select * from public.former_students;
```

> 나갔던 학생이 돌아오면 예전 기록이 그대로 이어집니다.

### 맞추는 방법

시트를 고치신 뒤 **저(클로드)에게 "시트 바꿨어" 라고만 말씀해주세요.**
시트를 읽어서 바뀐 부분만 반영하고, 무엇이 달라졌는지 알려드립니다.

안전장치도 넣어두었습니다.
- 읽어온 명단이 50명 미만이면 실행하지 않습니다 (시트를 잘못 읽었을 때 대비)
- 빈 명단으로는 실행되지 않습니다 (전체가 사라지는 사고 방지)
- 이름 뒤의 영문 구분자(`김지우A` 의 `A`)는 자동으로 떼어집니다

## 9. 출제된 문제 누적하기

`supabase-문제은행.sql` 을 한 번 실행해두면, 학생이 시험을 볼 때마다
**어떤 문제가 나왔고 누가 맞혔는지**가 한 문항씩 쌓입니다.

| 표 | 담기는 내용 |
|---|---|
| `questions` | 문제 은행 (회차 · 어휘 · 한자 · 정답 · 보기 · 해설) |
| `attempt_items` | 출제 기록 (시험 한 번에 나온 문제 하나가 한 줄) |

**앱은 고치지 않아도 됩니다.** 지금도 앱이 보내고 있는 자료를 수파베이스가 알아서 풀어서 쌓습니다.

### 많이 틀리는 어휘 보기

`SQL Editor` 에서 아래를 실행하면 정답률이 낮은 순서로 나옵니다.

```sql
select * from public.question_stats
 where 출제횟수 > 0 order by 정답률;
```

### 회차를 새로 추가했을 때 — 버튼 한 번

선생님용 화면 맨 아래 **`문제 은행에 올리기`** 를 누르면,
앱에 들어 있는 문제 전부(보기·해설 포함)가 수파베이스로 올라갑니다.

- 새 문제는 새로 들어가고, 이미 있는 문제는 내용이 최신으로 맞춰집니다
- 여러 번 눌러도 중복으로 쌓이지 않습니다
- 처음 한 번은 `SQL Editor` 에서 `supabase-문제은행.sql` 을 실행해두어야 합니다

> 이 버튼을 누르지 않아도 **학생이 처음 풀 때 자동으로** 등록되지만,
> 그때는 보기와 해설 없이 어휘와 정답만 들어갑니다.

---

### 기록을 엑셀로 받기

선생님용 화면 맨 아래 **`엑셀(CSV)로 내려받기`** 버튼을 누르면
보고 있는 기록이 CSV 파일로 내려받아집니다. 엑셀에서 바로 열립니다.

## 10. 지금 들어 있는 기능

- **회차 선택 화면** (회차마다 이름·설명·문제 수 표시)
- 학생 이름 · 학교 · 학부모님 전화번호 뒷 4자리 입력 후 시작
  (빈칸이 있으면 무엇을 채워야 하는지 알려줍니다)
- 지난번에 시험 본 학생이면 입력칸을 자동으로 채워 줍니다
- 한 화면에 **한 문제씩**, 4지선다
- 회차마다 **15문제 · 한자성어 3개 포함**
- 위쪽에 `3 / 10` 진행 표시와 진행 막대
- 보기를 골라야 "다음 문제" 버튼이 켜집니다
- 마지막 문제에서는 버튼이 "결과 보기"로 바뀝니다
- 결과 화면: 점수, 정답률, 격려 문구
- **틀린 문제만** 모아서 `내 답 / 정답 / 해설` 표시
- **선생님이 정한 이번 주 숙제 회차만** 학생에게 보임
- **재원생 명단에 있는 학생만 시험 시작 가능** (앱과 서버 양쪽에서 확인)
- "이 회차 다시 풀기" 버튼 (다시 풀면 문제와 보기 순서가 새로 섞입니다)
- 어휘 아래 한자 표시 (`hanja` 를 비워두면 표시되지 않습니다)
- **점수 기록 저장**과 **내 지난 기록 보기** (본 회차 수, 시험 횟수, 평균 정답률)
- 기록 CSV 내려받기 (선생님용)
- **선생님용 화면 분리** (teacher.html — 회차별 평균, 학생별 누적, 정렬, CSV 내려받기)
- **재원생 명단 연결** (학생별 성적 누적, 아직 안 본 학생 표시)
- **출제된 문제 누적** (어휘별 출제 횟수와 정답률)
- **시트 변동 반영** (추가·퇴원 학생 처리, 나간 학생 기록 보존)
- 연보라 계열 색과 큰 글씨로 휴대폰에서 읽기 편하게 구성
  (어두운 화면 설정에서도 잘 보입니다)
